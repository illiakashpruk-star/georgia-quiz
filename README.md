# Що? Де? Коли? Грузинський вечір

Гра для компанії: дзиґа обирає питання, хвилина на обговорення, бал знавцям або ведучому.
Працює в браузері на будь-якому пристрої, нічого встановлювати не треба.

Питання в коді закодовані, тож якщо випадково відкриєш файл, нічого не прочитаєш.

## Як викласти на GitHub Pages (5 хвилин)

1. Зайди на github.com і натисни **New repository**. Назва, наприклад, `georgia-quiz`, тип **Public**. Натисни **Create repository**.
2. На сторінці репозиторію натисни **uploading an existing file** (або **Add file → Upload files**).
3. Перетягни файли `index.html` і `README.md`, натисни **Commit changes**.
4. Відкрий **Settings → Pages**. У блоці **Build and deployment** обери **Source: Deploy from a branch**, гілку **main** і папку **/ (root)**. Натисни **Save**.
5. Почекай 1–2 хвилини й онови сторінку. Зверху з'явиться посилання вигляду
   `https://твій-нікнейм.github.io/georgia-quiz/`

Кидай це посилання друзям і грайте з телефона, ноутбука чи телевізора.

## Правила коротко

- Крутіть дзиґу, стрілка обирає питання.
- Той, у кого телефон, читає питання вголос і запускає таймер (60 секунд).
- Капітан називає відповідь, відкриваєте правильну і віддаєте бал.
- Бліц: 3 питання по 20 секунд, бал знавцям лише за три правильні.
- Режими: до 6 балів (як у телегрі) або всі 20 питань.

Прогрес зберігається в браузері, тож вкладку можна закрити й продовжити пізніше.
